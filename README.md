# EP2---Design-de-Software-
Exercício de programa 2. Design de Software. Dependência de férias.

Fortuna DesSoft

O Fortuna DesSoft é um jogo de perguntas e respostas feito em Python, inspirado no Show do Milhão.

O jogador responde questões fáceis, médias e difíceis para acumular prêmios, podendo chegar a R$ 1.000.000. Durante o jogo, também é possível usar 3 pulos e 2 ajudas.

Como jogar:

Execute o arquivo principal com o comando:

python jogo.py

Durante o jogo, digite:

A, B, C ou D para responder;
AJUDA para eliminar alternativas erradas;
PULA para trocar de questão;
PARAR ou CONTINUAR após acertar.

Se o jogador errar, perde todo o prêmio acumulado.

Arquivos
jogo.py: executa o jogo;
funções.py: contém as funções utilizadas;
base_questoes.py: contém as perguntas do jogo.

Projeto desenvolvido para a disciplina de Design de Software.
